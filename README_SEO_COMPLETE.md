## Troubleshooting

### Pages Not Indexing?
1. Check Google Search Console
2. Verify robots.txt allows page
3. Check URL is in sitemap
4. Use "Request Indexing" in GSC
5. Wait 24-48 hours

### Rankings Not Improving?
1. Give it 4-6 weeks minimum
2. Check keyword difficulty
3. Verify content quality
4. Build backlinks
5. Ensure Core Web Vitals pass

### Performance Issues?
1. Check PageSpeed score
2. Run Lighthouse audit
3. Verify images optimize
4. Check cache headers
5. Review bundle size

### Search Console Errors?
1. Review error report in GSC
2. Fix underlying issue
3. Retest with Inspector
4. Resubmit for indexing
5. Monitor for resolution
