## 🆘 Troubleshooting

### Pages Not Indexed?
```
1. Check GSC Coverage report
2. Verify robots.txt allows page
3. Check sitemap includes page
4. Use "Inspect URL" in GSC
5. Request indexing
6. Wait 24-48 hours
```

### Low Core Web Vitals?
```
1. Run PageSpeed Insights
2. Reduce image sizes
3. Minimize CSS/JS
4. Enable caching
5. Optimize fonts
6. Use CDN
```

### No Traffic Increase?
```
1. Verify proper tracking
2. Check keyword difficulty
3. Build more backlinks
4. Improve content quality
5. Add FAQ content
6. Be patient (wait 2-3 months)
```
